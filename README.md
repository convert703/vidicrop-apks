# Vidicrop pour Android

Téléchargez des vidéos et de la musique sans filigrane, convertissez vos images, retirez l'arrière-plan d'une photo et convertissez vos fichiers de données, directement depuis votre téléphone.

Ce dépôt contient uniquement les fichiers d'installation (APK) de l'application Android **Vidicrop**. Le site officiel est [www.vidicrop.com](https://www.vidicrop.com).

---

## 📥 Télécharger

👉 **[Télécharger la dernière version](https://github.com/convert703/vidicrop-apks/releases/download/v1.0.5/vidicrop.apk)**

Sur la page qui s'ouvre, touchez **`vidicrop.apk`** dans la section **Assets**.

Vous pouvez aussi passer par le site : [www.vidicrop.com/download/android](https://www.vidicrop.com/download/android)

**Configuration requise :** Android 7.0 ou plus récent.

---

## 📲 Installer

1. Téléchargez **`vidicrop.apk`** sur votre téléphone.
2. Ouvrez le fichier (depuis la notification de téléchargement ou l'application **Fichiers**).
3. Si Android affiche *« Pour votre sécurité, l'installation d'applications inconnues est bloquée »* :
   - touchez **Paramètres** ;
   - activez **Autoriser depuis cette source** ;
   - revenez en arrière.
4. Touchez **Installer**.
5. Si **Play Protect** affiche un avertissement, touchez **Plus de détails**, puis **Installer quand même**. Cet avertissement est normal pour une application distribuée en dehors du Play Store.

---

## 🔄 Mises à jour

Vous n'avez **rien à faire** : quand une nouvelle version est disponible, Vidicrop vous la propose au démarrage (**« Nouvelle version disponible »**).

1. Touchez **Mettre à jour** : le téléchargement se fait dans l'application.
2. Confirmez **Mettre à jour** dans la fenêtre d'Android.

✅ Votre compte et vos fichiers sont conservés.

> La première fois, Android peut vous demander d'autoriser Vidicrop à installer des applications. Activez l'option, puis revenez dans l'application : la mise à jour continue toute seule.

## 🔐 Vérifier le fichier (facultatif)

Chaque version publiée indique l'empreinte **SHA-256** de son APK. Pour vérifier que votre fichier est authentique et complet :

**Windows (PowerShell)**
```powershell
Get-FileHash .\vidicrop.apk -Algorithm SHA256
```

**macOS / Linux**
```bash
shasum -a 256 vidicrop.apk
```

Le résultat doit être identique à l'empreinte indiquée dans la description de la version.

## ❓ Problèmes fréquents

| Problème | Solution |
|---|---|
| « Application non installée » | Désinstallez l'ancienne version de Vidicrop, puis réinstallez. |
| « Le fichier est corrompu » | Le téléchargement a été interrompu : téléchargez à nouveau l'APK. |
| Le bouton **Installer** est grisé | Fermez les applications qui s'affichent par-dessus l'écran (bulles de discussion, filtre de lumière bleue), puis réessayez. |
